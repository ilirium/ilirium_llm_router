have seen it.

**The second phase wrote no such file at all**, and that carries more weight than any single entry:
a practice invented without a rule reached exactly one phase. *It is the argument for "the file
always exists".*

**One thing left standing, and it is the trap for the next reader.** Eleven entries, none marked
answered — and under this document **that is not a defect**, it is what a one-way channel looks
like. The instinct is to treat that file as a backlog of unanswered questions; a reader who acts on
it will re-raise things the owner already chose not to spend attention on.
