Captured by evidence/clienthello-capture.py, which is a socket with no certificate: a
ClientHello is plaintext and arrives BEFORE cert validation, so the client is seen and then
fails. No Anthropic traffic, no credential, nothing installed.

  python3 clienthello-capture.py <port> <label>   then point the client at https://127.0.0.1:<port>

DIFFERENCES
  8 of 17 cipher suites differ, and the shared ones are in a different order.
  python offers ext 22 (encrypt_then_mac); claude does not.
  claude offers ext 5 (status_request) and 18 (SCT); python does not.
  python offers 8 supported groups, claude 4.

The absence of encrypt_then_mac together with status_request + SCT and a short group list is
BoringSSL-shaped rather than OpenSSL-shaped. Claude Code ships as a compiled single-file
binary, which is consistent with a Bun build. Stated as INFERENCE from the fingerprint --
the measured fact is only that the two hellos differ.
