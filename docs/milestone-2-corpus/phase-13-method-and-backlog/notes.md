## Why this phase amends a rule set two days before it opened

**Settled row 9 changes `IDM-001`**, which currently says that filing a backlog item **is** how a
phase declines scope — a rule the owner set on 2026-09-02, two days before this phase opened.

**What changes is the authority, not the mechanism.** Filing remains the record of a decline. What
the owner added on 2026-09-04 is that the item lands **on their word**: a session asks, and if the
answer is no the decline is recorded in `notes.md` instead. The reason given was that a large
backlog is not itself a good outcome.

**The branch rule is untouched** — an item never opens a branch of its own, which is the part of
that section the 2026-09-02 amendment exists for.

*Recorded here rather than only in `IDM-011`, because a reader will otherwise ask why a rule two
days old was amended by the next phase.*
